# Decisions

Every decision an agent or the factory takes on this product is recorded here,
one file per ticket, named after the ticket (`T<number>-<slug>.md`) so that two
tickets never compete for the same file name.

Each record states: the decision, the alternatives considered, why this one,
what it brings, its risks and drawbacks, and how to reverse it. A human can
revisit any of them at any time by opening a ticket that references the record.
